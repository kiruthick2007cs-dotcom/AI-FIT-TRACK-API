# FITTRACK — 8-Phase Project Package

This repository organizes the **FITTRACK** B.Sc Computer Science project into eight academic project phases.

## Verified project basis
The supplied project materials describe **AI FitTrack API**, a RESTful fitness tracking backend built with Node.js, Express.js, MongoDB/Mongoose, JWT authentication, bcryptjs, Morgan, and Google Gemini SDK. The documented capabilities are user authentication, workout management, workout search, AI workout recommendation, and AI fitness insights.

## Important source-material note
The uploaded materials contained the README, package manifests, `.env.example`, `.gitignore`, and Postman collection. The actual JavaScript source files under `src/` were not uploaded in this submission. Therefore, this package does **not** invent or reproduce missing controller, model, route, middleware, service, `app.js`, or `server.js` source code.

## Security
The supplied `.env` file was intentionally excluded because it contains credential values. Only `.env.example` is included in the project package.

## Phases
1. Brainstorming and Ideation
2. Requirement Analysis
3. Project Design
4. Project Planning
5. Project Development
6. Project Testing
7. Project Documentation
8. Project Demonstration

## Usage
Open each phase folder and its README for the phase-specific documentation. The Phase 5 folder contains the supplied project metadata and Postman collection. Phase 6 testing records distinguish documented/expected behavior from tests that were not actually executed in this package.

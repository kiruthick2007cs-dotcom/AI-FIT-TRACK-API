# FitTrack API Testing

The supplied `FitTrack.postman_collection.json` is the actual collection provided with the project.

Collection groups:
- Authentication
- Workouts
- AI Assistance

The collection uses `base_url=http://localhost:5000`, `jwt_token`, and `workout_id` variables. Registration/login test scripts can store a JWT token, and Add Workout can store a workout ID.

No live API response files were supplied, so this package does not fabricate execution results.
